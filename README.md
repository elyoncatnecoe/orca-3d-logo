# 虎鲸 3D Logo · 可打印重建版

把一张扁平的虎鲸 Logo 轮廓，参数化重建为**封闭流形、可直接 3D 打印**的三维模型，并在浏览器里实时预览、一键导出 STL。

整个项目就是**一个 HTML 文件**（`index.html`），零构建、零安装，双击即用。

> 拖动旋转 · 滚轮缩放 · 右键平移

在线预览：https://elyoncatnecoe.github.io/orca-3d-logo/

## 功能

- **参数化几何重建**：身体、背鳍、胸鳍、尾鳍、眼斑/眼睛浮雕全部由 SVG 轮廓线程序化生成，纯 JavaScript 计算，不依赖建模软件。
- **水密性保证**：每个零件自身都是封闭流形（每一条边恰好被两个三角面共享），并实时统计开边、非流形边与退化面数量。
- **布尔合并**：通过 `manifold-3d`（WASM）把所有零件合并为**单一实体**，得到真正可以切片打印的 STL；离线时会退化为重叠壳体版本并给出提示。
- **真实毫米尺寸**：面板以毫米为单位输入打印长度，导出前自动换算并**居中落床**、Z 轴向上、二进制 STL。
- **实时着色预览**：three.js 查看器支持着色 / 线框 / 自动旋转切换，合并结果可直接在视图中查看。

## 使用

1. 用浏览器打开 `index.html`（或访问上面的在线预览地址）。
2. 在左侧面板调整参数，模型会实时重建。
3. 点「**合并 & 检查**」确认水密性与体积。
4. 点「**导出 STL**」，得到 `orca_<长度>mm.stl`，直接丢进切片软件。

首次合并 / 导出需要联网加载 `manifold-3d` 的 WASM 模块。

## 参数

| 参数 | 范围 | 默认 | 说明 |
| --- | --- | --- | --- |
| 打印长度 | 40 – 220 mm | 100 mm | 模型总长，决定毫米换算比例 |
| 最薄边宽 | 0.5 – 2 mm | 1.0 mm | 鳍边缘最小厚度下限，按此约束透镜形截面 |
| 鳍厚度 | 0.6 – 1.8 | 1.0 | 鳍根部厚度系数 |
| 鳍/尾弧度 | 0 – 2 | 1.0 | 沿翼展的弯曲（camber）幅度 |
| 眼斑浮雕 | 0 – 1.5 mm | 0.8 mm | 眼斑与眼睛凸出高度 |
| 底部压平 | 开关 | 开 | 切平腹部，方便平放打印 |
| 压平深度 | 0 – 0.6 | 0.25 | 压平量 |
| 着色 / 线框 / 旋转 | 开关 | 着色 + 旋转 | 查看器显示选项 |

## 实现要点

- **身体**：绕曲线中轴的结构化旋成体，两端收敛为单顶点，无退化三角面。
- **鳍**：按原 SVG 轮廓做「两条边缘线放样」的结构化网格；厚度由到边缘的距离决定，沿翼展渐薄形成透镜形截面，并带有弯曲。
- **坐标系**：内部以模型单位计算，导出时按 `mmPerUnit()` 统一换算为毫米。

主要代码集中在 `index.html` 内的一个 IIFE 中，大致分为三段：几何构造（`buildOrca` 及各零件构造函数）、three.js 查看器、布尔合并与 STL 导出。
